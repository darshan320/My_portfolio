HuggingRAG — Zero-Cost RAG Chatbot

AI / RAG / NLP
Built during internship at Dlithe Consultancy Services Pvt. Ltd. (Jun 22 – Aug 21, 2026)
Overview

A fully open-source Retrieval-Augmented Generation (RAG) chatbot that answers questions grounded in a custom document knowledge base, without relying on any paid LLM APIs. Built entirely on free Hugging Face models, the system combines semantic vector search, keyword-based retrieval, and conversational memory to deliver accurate, hallucination-resistant answers through a deployable web interface. This project was developed as part of a data science and machine learning internship, applying concepts including data preprocessing, model building, and evaluation to a real-world NLP application.

Approach
  • Built an ingestion pipeline that chunks source documents and embeds them locally using a free sentence-transformer model, storing vectors in a persistent ChromaDB store.
  • Implemented a hybrid retriever combining dense vector search with BM25 keyword search via LangChain's EnsembleRetriever, improving accuracy on queries with exact terms or figures.
  • Designed a history-aware query rewriting step so follow-up questions are resolved using prior conversation context, enabling natural multi-turn dialogue.
  • Wrapped the pipeline in a Streamlit chat interface with live per-user document upload, using an isolated in-memory vector store per session to keep uploaded data private.
Outcome

A fully functional, deployable chatbot that answers document-grounded questions with zero API cost, correctly declines to answer when information isn't present in retrieved context, and supports live user-uploaded knowledge — all running on free, open-source models.

Network Congestion Prediction — Multi-Model Ensemble with Bootstrap Sampling

Networks
Overview

A machine learning project that generates synthetic network performance data and builds an ensemble Voting Classifier to predict network congestion, combining multiple base learners into a single, more robust predictive model.

Approach
  • Generated a synthetic dataset simulating network metrics — latency, packet loss percentage, bandwidth usage, and active user count — with built-in correlation logic linking high latency, packet loss, and user load to congestion.
  • Applied bootstrap sampling to create three distinct resampled subsets of the data, giving each base model a slightly different view of the training distribution.
  • Trained three base classifiers — K-Nearest Neighbors, Decision Tree, and Logistic Regression — each on its own bootstrap sample.
  • Combined the base models into a hard-voting Ensemble Voting Classifier and evaluated it against each individual model using classification reports, accuracy scores, and confusion matrices.
Outcome

The ensemble model matched or outperformed the individual base classifiers, illustrating how combining diverse learners on bootstrapped data reduces variance and produces a more reliable congestion classifier than any single model alone.

Adaptive Smart Fan Controller

IoT / Embedded
Overview

A closed-loop temperature control system built around an ESP32 microcontroller. The system continuously samples ambient temperature and drives a PWM-controlled fan through a tuned PID algorithm, holding the target temperature within a tight tolerance band regardless of changing ambient conditions or load.

Approach
  • Implemented a PID control loop in firmware to dynamically adjust fan PWM duty cycle based on real-time temperature error.
  • Built a BLE telemetry layer to stream live temperature, fan speed, and system status to a companion mobile dashboard.
  • Added Over-The-Air (OTA) firmware update support, allowing the controller logic to be updated remotely without re-flashing over USB.
  • Tuned PID gains experimentally to minimize overshoot while keeping response time fast under sudden thermal load changes.
Outcome

The final system holds temperature within ±0.5°C of the target setpoint, automatically adapting fan speed in real time, while remaining fully maintainable in the field through OTA updates.

Ensemble TinyML Classifier on Edge

ML Research
Overview

An ensemble classifier combining a decision-tree model and a compact neural network, compressed and deployed directly onto an STM32 microcontroller for fully on-device gesture recognition — no cloud inference required.

Approach
  • Trained and compared decision-tree and neural-network models on a 6-class gesture dataset, then combined them into an ensemble to improve robustness.
  • Used Edge Impulse to handle data pipeline management, model optimization, and quantization for microcontroller deployment.
  • Converted the trained model to TensorFlow Lite format to minimize memory footprint and inference latency on constrained hardware.
  • Profiled inference time and RAM usage directly on the STM32 to validate real-time feasibility.
Outcome

The deployed ensemble reaches 94.2% classification accuracy across all 6 gesture classes, with inference completing in under 15ms and a total RAM footprint of just 64KB — well within the constraints of the target microcontroller.
